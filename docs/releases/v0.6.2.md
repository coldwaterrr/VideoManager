# VideoManager 0.6.2

本次集中更新媒体库交互、预览性能和系列整理。

- 重构深色媒体库：侧栏导航、网格/列表、组合筛选、批量操作和键盘交互。
- 修复普通最小化时任务栏图标消失，补齐应用与托盘图标，支持托盘恢复、隐藏和退出。
- 本地封面与预览写入磁盘缓存，重启复用，优先准备当前页；文件变化后更新，约 1GB 自动回收。
- 悬停后随机播放不同位置的片段，每段 3–5 秒并预载下一段；跟随原片帧率，最高 30fps，鼠标移开停止。
- 新增本地系列识别：按目录、编号和相近名称给出可编辑建议，支持手动成组、折叠、展开、改名与解散，保持原文件位置。
- 保留目录自动检测、规则与 AI 分类、备份清理、Web/MPV/系统播放。

## Windows x64 下载

- `VideoManager-Windows-0.6.2-Setup.exe`：安装版，可选择目录，卸载时保留用户数据。
- `VideoManager-Windows-0.6.2-Portable.exe`：单文件免安装版。
- `VideoManager-Windows-0.6.2-x64.zip`：解压后运行 `VideoManager.exe`。

均包含 FFmpeg 和 MPV，无需另装 Node.js 或播放器。默认用户数据保存在 `%APPDATA%\VideoManager`；便携版也复用此用户数据位置。

`latest.yml` 和 `.blockmap` 用于应用内更新，`SHA256SUMS.txt` 可用于校验下载文件。FFmpeg 的许可证与源码信息随程序保存在 `media-tools/` 中。
